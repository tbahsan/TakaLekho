# টাকালেখো — Scope Contract (v0.1.0)

> এই নথি repository-র চুক্তি। বড় কোনো feature যোগ করার আগে এখানকার শর্ত বদলাতে হবে,
> এবং সেই বদল PR-এ আলাদাভাবে দেখাতে হবে।

## ১. Target user

বাংলাদেশের ব্যবহারকারী, যাঁরা টাকার অঙ্ক কথায় লিখতে হয় — চেক, দলিল, ভাউচার, দানপত্র,
স্মারকলিপি বা দৈনন্দিন হিসাবের টীকা। ইনপুট সাধারণত বাংলা বা ইংরেজি অঙ্কে টাইপ করা হয়,
তারপর সেই লেখাটি হাতে-কপি করে অন্য জায়গায় বসাতে হয়।

## ২. MVP promise

> বৈধ টাকা-পয়সার পরিমাণকে **দেশীয় সংখ্যা-রীতিতে** (কোটি–লাখ–হাজার–শতক–একক) বাংলা কথায়
> লেখা — কোনো অনুমান নয়, কোনো গোপন রাউন্ডিং নয়।

বাক্যের শেষে নির্দিষ্ট শব্দ-রীতি (ডিফল্ট: দাপ্তরিক) ছাড়া অন্য কিছু নিজে থেকে অনুমান করা হয় না।

## ৩. Supported input

| বিষয় | নিয়ম |
|---|---|
| অঙ্কের লিপি | বাংলা (০-৯) **অথবা** ইংরেজি (0-9) — একই ইনপুটে দুটো মিশিয়ে নয় |
| পরিসর | `০` থেকে `৯৯,৯৯,৯৯,৯৯৯.৯৯` (999,999,999.99) |
| কমা | ঐচ্ছিক; থাকলে দেশীয় রীতিতে `1,23,45,678` |
| দশমিক | `.` একটি, সর্বোচ্চ দুই ঘর (`12.5`, `12.50`) |
| শুরুতে | ঐচ্ছিক একবার `৳` (এর পরে ফাঁকা জায়গা চলবে) |
| বাইরের ফাঁকা | ট্রিম করা হয় |
| ইনপুটের দৈর্ঘ্য | সর্বোচ্চ ৬৪ অক্ষর |

## ৪. Invalid input → নির্দিষ্ট ত্রুটি (কখনো অনুমান নয়)

| ইনপুট | কোড | কারণ |
|---|---|---|
| `""`, `"   "` | `EMPTY_INPUT` | কিছু লেখা হয়নি |
| `12.005` | `DECIMAL_DIGITS` | দুই ঘরের বেশি দশমিক |
| `12.` | `DECIMAL_POINT_NO_DIGITS` | দশমিকের পরে অঙ্ক নেই |
| `.50` | `DECIMAL_POINT_MISSING_ZERO` | দশমিকের আগে অঙ্ক নেই |
| `1.2.3` | `DECIMAL_POINT_REPEATED` | একাধিক বিন্দু |
| `007`, `০১২`, `00` | `LEADING_ZERO` | অপ্রয়োজনীয় শূন্য |
| `100,000` | `GROUPING_UNSUPPORTED` | ইংরেজি রীতির কমা |
| `1,0000`, `12,34`, `1,,000` | `GROUP_INVALID` | কমার বিন্যাস ভুল |
| `-12`, `−12` | `NEGATIVE_NOT_SUPPORTED` | ঋণাত্মক |
| `+12` | `SIGN_NOT_SUPPORTED` | যোগ চিহ্ন |
| `1e3` | `EXPONENT_NOT_SUPPORTED` | বৈজ্ঞানিক রূপ |
| `১২3` | `MIXED_DIGIT_SCRIPT` | দুই লিপি মেশানো |
| `12 450` | `WHITESPACE_INSIDE` | মাঝে ফাঁকা |
| `১২ টাকা`, `12 taka` | `UNIT_WORD_IN_INPUT` | ইনপুটে একক লেখা |
| `abc`, `১২৩` (আরবি-ইন্দিক) | `INVALID_CHARACTER` | অননুমোদিত অক্ষর |
| `12৳`, `৳৳12` | `CURRENCY_SYMBOL_POSITION` | ৳ ভুল স্থানে |
| ১০ অঙ্কের মান | `OUT_OF_RANGE` | ঘোষিত সীমার বাইরে |

প্রতিটি ত্রুটির সঙ্গে **কারণ** ও **সমাধানের ইঙ্গিত** দেখানো হয়। ত্রুটি থাকা অবস্থায়
পুরোনো ফলাফল স্ক্রিনে থাকতে পারে না, কপি/ডাউনলোড করা যায় না।

## ৫. Output policy

| নিয়ম | সিদ্ধান্ত |
|---|---|
| কোটি/লাখ/হাজার | পূর্ণ শব্দে লেখা হয় (`কোটি`, `লাখ`, `হাজার`) — কখনো `কো0` নয় |
| শতক | ডিফল্টে `একশত … নয়শত`; পরীক্ষামূলক কথ্য রীতিতে `একশ … নয়শ` |
| শূন্য গোষ্ঠী | বাদ পড়ে (কখনো “শূন্য লাখ”, কখনো মাঝখানে “ও”) |
| পয়সা | শূন্য হলে পুরো পয়সার অংশ বাদ; `12.05` → “পাঁচ পয়সা” (শূন্য উচ্চারিত হয় না) |
| টাকা শূন্য | `0.01` → “শূন্য টাকা এক পয়সা মাত্র” — “শূন্য টাকা”-কে সরানো হয় না |
| `মাত্র` | ডিফল্ট রীতিতে বাক্যের শেষে **একবারই** |
| রাউন্ডিং | কখনো নয় — `12.005` গ্রহণযোগ্য নয়, কারণ তাতে পয়সার মান বদলে যেত |
| রীতি বদল | শুধু labels/সেটিংস; সংখ্যার মান কখনো বদলায় না |

### ৫.১ রীতি (presets)

| id | নাম | শতক | “মাত্র” | ডিফল্ট | অবস্থা |
|---|---|---|---|---|---|
| `official` | দাপ্তরিক | `শত` | হ্যাঁ | হ্যাঁ | pending independent review |
| `colloquial` | কথ্য ও সংক্ষিপ্ত | `শ` | না | না | experimental, not reviewed |

নতুন রীতি যোগ করার শর্ত: ডেটা + আলাদা contract + reviewer + golden fixtures।

## ৬. Out of scope (v0.1.0)

- ঋণাত্মক পরিমাণ, “ঋণ”/“Dr/Cr” ভাষা।
- আন্তর্জাতিক রীতি (million/billion) বা `1,000,000` বিন্যাস — v0.2-এ আলাদা contract।
- ব্যাংক/আইনগত অনুমোদিত দলিল-রূপ (legal-tender wording) হিসেবে কোনো দাবি।
- ইংরেজি কথায় রূপান্তর, বানান-সংশোধন, সংখ্যাকে অঙ্কে ফেরানো (reverse)।
- টাকার ইতিহাস/হিসাব সংরক্ষণ, ব্যাকএন্ড, লগইন, ক্লাউড সিঙ্ক, বিশ্লেষণ (analytics)।
- handwriting/typography বা দলিলের ফরম্যাট।

## ৭. Uncertainty policy

এই অ্যাপে **কোনো অনিশ্চয়তা নেই** — সব রূপান্তর নির্ধারিত (deterministic) এবং একই ইনপুটে
সব সময় একই ফল দেয়। অনিশ্চয়তা কেবল দুটি জায়গায় ঘোষণা করা হয়:

1. **শব্দ-তালিকার ভাষাগত শুদ্ধতা** — স্বাধীন পর্যালোচক এখনো অনুমোদন দেননি
   (`reviewStatus: pending-independent-review`, `docs/EVALUATION.md`)।
2. **“কথ্য ও সংক্ষিপ্ত” রীতি** — পরীক্ষামূলক, UI-তে সেটি লেখা থাকে।

## ৮. Performance ও limits

- ইনপুট সর্বোচ্চ ৬৪ অক্ষর, সর্বোচ্চ ৯ অঙ্ক → বিশ্লেষণ main thread-এ, কোনো worker ছাড়াই,
  keystroke-প্রতি খরচ অণুপাতিকভাবে নগণ্য।
- কোনো ফাইল/ব্যাচ ইনপুট নেই, তাই progress UI নেই।
- Binary বাজেট লক্ষ্য: core JS+CSS gzip ~১০ KB; font/icon আলাদা (README-তে মাপা হিসাব)।

## ৯. Storage contract

- **ডিফল্ট: কিছুই সংরক্ষিত হয় না।** ইনপুট শুধু মেমরিতে থাকে।
- ঐচ্ছিক (opt-in) করলে দুইটি কী লেখা হয়: `takalekho.settings.v1`, `takalekho.history.v1`
  (সর্বোচ্চ ২০টি সাম্প্রতিক হিসাব, একই মান+রীতি হলে ডুপ্লিকেট নয়)।
- চাইলে এক ক্লিকে সব মুছে ফেলা যায় (“সংরক্ষিত সব মুছুন”)।
- Storage বন্ধ/ভর্তি/ব্লকড হলে অ্যাপ কাজ করা চালিয়ে যায়, কিন্তু **কখনো মিথ্যা “সংরক্ষিত” বার্তা দেয় না**।
- ভাগ করা কম্পিউটারের জন্য session-only ব্যবহারই সুপারিশ করা হয় (README-তে লেখা)।
